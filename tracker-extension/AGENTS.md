- Branta Tracker extension source lives here (own package, excluded from Console lint/tsc; ZIP builds go to Files); one active browser per employee via Tracker auth user_metadata.tracker_device with explicit takeover confirmation — why: the Shift lives on the server so a handover never resets time, and a second browser must never record overlapping intervals.
- Tracker extension ZIPs are hosted in Cloudflare R2 (downloads/tracker/…), served via /downloads/tracker-extension redirect; version in src/lib/tracker-release.ts — why: keep binaries out of the repo and build.
- Tracker Shift schedules are admin-edited only via tracker-schedule.functions.ts into Tracker app_metadata.shift_schedule; the extension computes Late/Early/Overtime — why: employees cannot edit app_metadata.
- Tracker SSO only via tracker-sso.functions.ts + /sso/tracker; server-only tracker.server.ts upserts one Tracker auth user per email; connected_apps revoke, never delete — why: one auditable path, no duplicates.
- Tracker employee mirror runs through the shared employee-app sync hooks and src/lib/tracker.server.ts (auth user + profiles + default settings; inactive = is_active false + Tracker ban) — why: Console is the only employee source of truth and a Tracker outage must never block Console changes.
